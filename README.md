# AURA — Chrome Extension (MV3)

AURA is a Manifest V3 Chrome extension that suggests (and optionally applies) readability/accessibility display modes based on local, on-device signals.  

## Scope (v5.2)
- MV3 only (background = service worker).
- No remote code / no `eval` / no modal dialogs.
- “Why?” opens the extension popup; **Chrome 127+** is required for `chrome.action.openPopup()`.
